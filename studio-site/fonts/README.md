# Fonts

Drop the licensed **Stretch Pro** file here as `StretchPro.woff2` (or `StretchPro.otf`).
`css/main.css` picks it up automatically; until then the headlines use
Archivo Black on its width axis as a stand-in, fitted to the exact cap heights
and letter positions of the frames.

Google Sans (Hebrew + Latin copy) loads from Google Fonts. To self-host it,
add an `@font-face` named `Google Sans` in `css/main.css`.
